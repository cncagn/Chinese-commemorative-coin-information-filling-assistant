# 中国农业银行纪念币预约填写助手

这是一个仅在中国农业银行纪念币预约页面运行的 Chromium 浏览器扩展，基于 DYexb 的“纪念币信息填写助手”修改。

## 功能

- 在本地保存多组预约人资料：姓名、身份证号、手机号、三级兑换网点层级和预约数量。
- 在农行纪念币预约页面填写 `name`、`identNo`、`mobile`。
- 依次填写农行兑换网点的级联下拉框：`orglevel1`（省级分行）、`orglevel2`（市级分行）、`orglevel3`（支行/区级机构）。每级会等待前一级触发页面生成下一级后再继续。
- 导入和导出本地 JSON 备份。

扩展只请求 `https://eapply.abchina.com/*` 的页面访问权限；资料保存在浏览器本地存储中。验证码需由用户自行接收并填写，扩展不会读取短信或自动提交预约。

## 安装

1. 在 Chrome 或 Edge 打开扩展管理页：`chrome://extensions/` 或 `edge://extensions/`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，并选择 `纪念币信息填写助手` 文件夹。

## 使用

1. 点击扩展图标，添加预约人资料。
2. 省级分行、市级分行、支行/区级机构请按农行页面选项的文字填写。例如：`山东省分行`、`济南分行`、`济南起步区分行`。
3. 点击扩展内的当前预约入口，或自行打开当期的农行纪念币预约页，等待页面加载完成。入口中的 `I205` 仅对应当前期次；期次更新后直接进入新的农行预约页即可，扩展不校验 `issueId`。
4. 在扩展中点击对应资料的“填入”，再自行检查页面内容、处理验证码并决定是否提交。
